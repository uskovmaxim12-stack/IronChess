# IRON CHESS

Полноценная браузерная шахматная игра с локальным скриптовым движком. Не требует установки, сервера, API-ключа или подключения к интернету после первого открытия (шрифты из Google Fonts необязательны).

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в актуальном Chrome, Edge или Firefox.
3. Выберите сторону, сложность и контроль времени.
4. Нажмите **«Начать партию»**.

## Реализовано
- Шахматная доска с координатами, выбором фигур и подсветкой легальных ходов.
- Правила: шах, мат, пат, рокировка, взятие на проходе, превращение пешки.
- Ничья по правилу 50 ходов, троекратному повторению позиции и недостаточному материалу.
- Локальный движок: minimax/negamax с alpha-beta pruning, iterative deepening, quiescence search, transposition table, move ordering, оценка материала и позиционных факторов.
- Сложность 1–5, подсказка, отмена хода, смена стороны, переворот доски, три темы оформления, часы.
- Журнал ходов и оценка позиции.
- SVG-фигуры в комплекте, не требуется скачивать ассеты.

## Структура
- `index.html` — интерфейс.
- `src/chess.js` — состояние позиции, генерация легальных ходов и правила.
- `src/engine.js` — поиск и оценка позиции.
- `src/app.js` — интерфейс и логика партии.
- `src/style.css` — оформление.
- `assets/pieces/` — SVG-фигуры.
- `docs/ARCHITECTURE.md` — заметки по архитектуре.

## Ограничения текущей версии
Это сильный для учебного браузерного проекта классический поисковый движок, но не уровень Stockfish. Сложность 4–5 может заметно нагружать браузер. Часы реализованы как локальный контроль времени; в этой версии нет онлайн-мультиплеера, сохранения партии в PGN, таблиц дебютов и полноценной базы эндшпилей. Перед публикацией на GitHub рекомендовано протестировать специальные шахматные позиции и партии на длинную дистанцию.
